# Frontend Placeholder

This directory is ready to receive frontend code.

## Expected Structure:
- Place your main entry point in `src/index.js` or `src/App.js`
- Public assets should go in the `public/` directory
- Source files should be in the `src/` directory

## Running the Frontend:
Once code is uploaded, run:
```bash
cd frontend
npm install
npm run dev
```

The package.json is configured to run the dev server with `npm run dev`.
