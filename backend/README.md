# Backend Placeholder

This directory is ready to receive backend code.

## Expected Structure:
- Place your main entry point in `src/index.js` or `src/server.js`
- Configuration files should go in the `config/` directory
- Additional source files should be in the `src/` directory

## Running the Backend:
Once code is uploaded, run:
```bash
cd backend
npm install
npm run dev
```

The package.json is configured to run the dev server with `npm run dev`.
